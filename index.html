Interactive math items, authored by AI, scored by a solver.

LidNote is a geometry engine that automates the creation of interactive math items for assessment and courseware providers. An author describes the item in a sentence. An agent constructs it as a live figure. A solver scores the student's interaction — the agent builds and the engine marks, ensuring outputs are always reliable.

The most expensive item type in assessment

Technology-enhanced items — drag a point, complete a geometric construction, manipulate a figure — test understanding in ways multiple choice cannot, and they score automatically at scale. Today, every one of them is made by hand.

Built by developers

Simulation-grade items are bespoke engineering: custom rendering and hand-written score logic, weeks per item pattern, maintained for years.

Or bought as labor

Content-service firms build interactives as billable hours. Single item cost is steep and this expense scales linearly with catalogue size.

AI authoring stops at text

AI item generation drafts multiple-choice, cloze and distractor item types across the industry. No tool authors complex interactive item types.

The gap the author describes the item — the AI builds it, the scoring is guaranteed. No platform solves for this.

How it works

Agent operation spec

The model plans the item via typed, deterministic operations against the engine — no freeform code generation.

Geometry kernel & solver

A scene graph with expression-linked parameters and a constraint solver holds one source of mathematical truth.

Interactive layer

Students drag, rotate and construct in 2D and 3D. Every gesture lands as semantic scene state, readable by solver and agent alike.

Authoring & delivery

Solution criteria, adaptive feedback from live scene read-back, and export into the platforms where items are delivered.
